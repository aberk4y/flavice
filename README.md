# Flavice 🍲
### Recipe Discovery & Meal Planning App

Flavice is a Flutter-based mobile application designed to make everyday meal planning easier. Users can explore recipes, browse food categories, search recipes by name or ingredients, save favorites, plan meals, and manage a shopping list.

> Developed as a mobile application course project at İstanbul Topkapı University.

## ✨ Features

- **Recipe discovery:** Browse recipes and explore popular meals.
- **Category browsing:** Find recipes by food category.
- **Recipe details:** View ingredients, preparation steps, cooking time, servings, and difficulty.
- **Search:** Search recipes using recipe names or ingredients.
- **Daily meal planning:** Add recipes to a daily meal plan and track the menu.
- **“What Should I Cook?”** Get a meal suggestion when you are unsure what to prepare.
- **Favorites:** Save recipes for quick access.
- **Shopping list:** Add ingredients, mark items as completed, and remove items.
- **Local storage:** Uses SQLite to store app data locally on the device.

## 🚀 Getting Started

### Requirements
- Flutter SDK compatible with the Dart SDK version specified in `pubspec.yaml`
- Android Studio or VS Code with Flutter support
- An Android emulator, iOS simulator, or compatible device

### Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/aberk4y/flavice.git
   ```
2. Open the project folder:
   ```bash
   cd flavice
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```

## 🗃️ Data Storage

Flavice uses SQLite for local data storage, allowing supported app data to remain available on the device without requiring a remote backend.
